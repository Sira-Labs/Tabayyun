# Logo assets

The mark is a lens holding a signal: a noisy trace on the left with one flagged point, and
the trace settling into a check mark on the right. Verify the report before acting on it,
which is what the name means. All files are flat SVG on a transparent background unless
noted.

| File | Use |
|---|---|
| `logo-light.svg` | Mark + wordmark, ink text, for light backgrounds |
| `logo-dark.svg` | Mark + wordmark, white text, for dark backgrounds |
| `logo-tagline-dark.svg` | Same with the tagline, for banners |
| `mark.svg` | Mark only |
| `icon.svg` | Simplified mark (no ring) on an ink tile with rounded corners, for favicons and avatars; reads at 16 px |
| `social-preview.svg`, `social-preview.png` | 1280×640 card for the repository's social preview (Settings → General → Social preview) and link previews |

Colours: ink `#0f172a` (also the web theme colour), teal `#0e9f8f` on light and `#5eead4` on
dark backgrounds, flag amber `#f59e0b`, muted text `#94a3b8`. The wordmark uses the system
sans-serif stack (Inter, Segoe UI, Helvetica Neue, Arial); outline the text before print.

The files are generated by `genlogo.py` (run it from the repository root with
`python3 docs/assets/genlogo.py`); the geometry lives in the `NOISE`, `CHECK` and `FLAG`
constants at the top of the script on a 400×400 grid. The script also copies `icon.svg` to
`web/public/favicon.svg` and `mark.svg` to `web/public/logo.svg`, then renders the PNGs with
headless Chromium: `social-preview.png` at 1280×640 and the raster icon fallbacks
`web/public/icon-180.png` (Apple touch icon), `icon-192.png` and `icon-512.png` (web app
manifest). It looks for a browser in `TABAYYUN_CHROMIUM`, on `PATH`, then in Playwright's
cache (`PLAYWRIGHT_BROWSERS_PATH` or `~/.cache/ms-playwright`); `--no-png` skips the step.
No fonts are embedded, so the wordmark uses the renderer's sans-serif.
